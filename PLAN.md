# Firmly roadmap

## Current scope

- Company research with optional website, industry, and headquarters context.
- Model and web research connection settings.
- Streamed research progress and recovery after connection loss.
- Conversation briefing, company, industry, financial, news, and references sections.
- PDF export and a saved, source-backed Cursor example.
- Responsive layouts, self-hosted Geist, keyboard focus states, and reduced-motion support.

## Before public release

- Run live research across varied companies, including ambiguous names and sparse public coverage.
- Review generated claims against their sources.
- Measure provider latency, usage limits, and interface performance.
- Complete keyboard, contrast, and long-content accessibility checks.
- Verify MongoDB persistence against a real database if enabled.
- Validate the deployment environment, streaming connections, and PDF dependencies.
- Add access controls and shared quotas before offering publicly accessible owner-funded research.

## Future scope

Comparisons, follow-up questions, saved reports, refresh history, monitoring, accounts, and billing require additional implementation.
